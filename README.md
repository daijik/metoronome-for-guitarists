# Metronome for Guitarists

ギタリスト向けのウェブメトロノームアプリ。練習時間のカウントダウンタイマーを内蔵し、設定した時間が経過すると自動で停止します。マイクを使うギターチューナーも使えます。

## 機能

- BPM 設定（30〜240）
- 拍子選択（2/4, 3/4, 4/4, 6/8）
- ビート表示（1拍目アクセントあり）
- 練習タイマー（プリセット or 任意の分数を設定、残り時間になると自動停止）
- ギターチューナー（マイク入力、音名・周波数・セントのズレを表示。標準 / 半音下げ / クロマチックに対応）

## 使い方

1. 練習時間を選択する（プリセット: 1/3/5/10/15/30分、または任意入力）
2. BPM と拍子を設定する
3. **Start** を押すとメトロノームとタイマーが同時に動き出す
4. 設定時間が経過すると自動停止。途中で止めたい場合は **Stop** を押す（タイマーはリセットされる）

### チューナー

1. 画面上部のタブで **チューナー** を選ぶ
2. チューニングを選ぶ（**標準** / **半音下げ** / **クロマチック**。ドロップ D など他のチューニングにはクロマチックを使う）
3. **Start** を押してマイクの使用を許可する
4. 弦を 1 本ずつ鳴らし、メーターが中央に来て緑色の **OK** になるまでペグを回す

マイクを使うため、HTTPS のページまたは localhost で開いてください。`dist/index.html` を直接開いた場合は、ブラウザによってチューナーを使えないことがあります。

## 開発環境

Node.js 18 以上が必要です。

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
# dist/ 以下に静的ファイルが生成される
```

生成された `dist/index.html` はサーバーなしでそのまま開けます（チューナーの制限は上記を参照）。

## 技術スタック

- React 19 + TypeScript
- Vite
- Web Audio API（lookahead scheduler による正確なタイミング制御）
